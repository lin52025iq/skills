# 前端迁移最终检查清单

此清单用于前端迁移结束前的独立总体验收。根据项目实际删减不适用项，但不能因为 Build 或 E2E 主流程通过就跳过生命周期、视觉和响应式检查。

## 一、功能生命周期

- [ ] 关键功能已经分类为 Active / Conditional / Hidden / Disabled / Deprecated / Removed / Unknown。
- [ ] 被注释的 JSX / Template / Route / Menu 已检查。
- [ ] Feature Flag、Permission、Tenant、Region、Env 条件已检查。
- [ ] 已查找旧页面 / 组件的替代实现。
- [ ] Deprecated / Removed 功能没有被错误恢复。
- [ ] Conditional / Hidden 但仍可达的功能没有被误删。
- [ ] Unknown 中没有影响发布的阻断项。

## 二、页面、路由与导航

- [ ] 迁移范围内关键页面完整。
- [ ] Route 注册符合要求。
- [ ] Nested / Lazy Route 正确。
- [ ] Menu / Sidebar / Navbar 正确。
- [ ] Tab / 页面内部导航正确。
- [ ] Deep Link 正确。
- [ ] Redirect 正确。
- [ ] Route Guard / Permission 正确。
- [ ] 404 / 无权限等页面行为正确。

## 三、功能与业务状态

- [ ] 关键用户流程通过。
- [ ] 关键业务规则得到验证。
- [ ] API 请求参数和响应处理正确。
- [ ] Mutation / Submit 正确。
- [ ] 防重复提交正确。
- [ ] Loading / Skeleton 正确。
- [ ] Empty 正确。
- [ ] Error 正确。
- [ ] Partial Data 正确。
- [ ] Disabled / Read-only 正确。
- [ ] Validation Error 正确。
- [ ] Permission Denied 正确。

## 四、交互

- [ ] Click / Input / Submit 行为正确。
- [ ] Modal / Drawer / Popover 打开关闭正确。
- [ ] Focus / Focus restore 正确。
- [ ] Keyboard 操作正确。
- [ ] Hover / Active / Selected 正确。
- [ ] Expanded / Collapsed 正确。
- [ ] Debounce / Throttle 语义正确。
- [ ] Optimistic Update 正确。
- [ ] Pagination / Infinite Scroll 正确。
- [ ] Scroll Restore / Scroll Owner 正确。
- [ ] Unsaved Changes 等离开提示正确（如适用）。

## 五、视觉还原

如果用户没有明确批准 redesign，以下项目默认应与源现役界面或批准基线对齐。

- [ ] Page Shell 对齐。
- [ ] Header / Sidebar / Main 结构对齐。
- [ ] 容器宽度和 max/min width 对齐。
- [ ] Grid / Flex / Position 行为对齐。
- [ ] margin / padding / gap 对齐。
- [ ] 字体家族、字号、行高、字重无未解释变化。
- [ ] 颜色 / 背景无未解释变化。
- [ ] Border / Radius / Shadow 无未解释变化。
- [ ] Icon / SVG / Image 尺寸和位置正确。
- [ ] 控件高度和密度正确。
- [ ] z-index / overlay 正确。
- [ ] overflow / scroll 行为正确。
- [ ] Sticky / Fixed 行为正确。
- [ ] Theme / Dark Mode 正确（如适用）。

## 六、响应式

- [ ] 源项目真实支持的 Desktop viewport 已验证。
- [ ] Tablet 已验证（如适用）。
- [ ] Mobile 已验证（如适用）。
- [ ] Breakpoint 下布局重排正确。
- [ ] Mobile / Desktop 隐藏项正确。
- [ ] Navigation 形态切换正确。
- [ ] Table / List / Card 响应式行为正确。
- [ ] 长文本、长列表和 overflow 已验证。
- [ ] 横竖屏等真实支持场景已验证（如适用）。

## 七、视觉回归证据

- [ ] 关键页面有源视觉基线。
- [ ] 关键 UI 状态有视觉基线或明确人工验收。
- [ ] Screenshot 比较环境尽量固定。
- [ ] 视觉差异已经分类。
- [ ] 非预期差异已经修复。
- [ ] 批准差异有明确记录。
- [ ] 没有通过随意扩大 diff threshold 掩盖回归。

## 八、目标前端项目一致性

- [ ] Router 使用目标项目现有方式。
- [ ] State / Data Fetching 使用目标项目现有方式。
- [ ] API Client 没有重复建设。
- [ ] Component Library / Design System 优先复用。
- [ ] Styling 使用目标项目约定。
- [ ] Design Token / Theme 处理符合目标项目。
- [ ] Error Handling 符合目标项目。
- [ ] Form 方案符合目标项目。
- [ ] i18n 符合目标项目。
- [ ] Test / Storybook / E2E 符合目标项目。

## 九、前端 Copy-Smell

- [ ] 没有把 `.vue` / Angular Component 机械一对一翻译为 React Component。
- [ ] 没有复制源页面组件树作为目标组件树。
- [ ] 没有把旧 Store module 一对一迁成新 Store module。
- [ ] 没有批量复制旧 mixin / helper / base component。
- [ ] 没有把旧 CSS / Less 架构机械复刻。
- [ ] 没有 Angular-shaped React / Vue-shaped React 等明显源框架形状。
- [ ] 没有重复实现目标项目已有 Component / Hook / Client / Layout。
- [ ] 没有因为目标组件库默认样式而静默改变页面视觉。

## 十、Accessibility

- [ ] 语义 HTML 合理。
- [ ] Button / Link 语义正确。
- [ ] Form Label / Accessible Name 正确。
- [ ] Keyboard Navigation 可用。
- [ ] Focus Order 合理。
- [ ] Focus-visible 可见。
- [ ] Dialog Focus Trap / Restore 正确。
- [ ] ARIA 使用合理。
- [ ] 关键 Contrast 问题已处理。
- [ ] Zoom / Text Resize 没有造成关键功能不可用。

## 十一、资源、国际化与平台

- [ ] Font 加载正确。
- [ ] Image / SVG / Icon 正确。
- [ ] Public Path / Asset Host 正确。
- [ ] Locale / i18n 正确。
- [ ] Date / Number Format 正确。
- [ ] Analytics / 埋点关键行为正确。
- [ ] SEO / Metadata 正确（如适用）。
- [ ] SSR / Hydration 正确（如适用）。
- [ ] Error Monitoring 接入正确。

## 十二、工程与性能

- [ ] Build / Type Check 通过。
- [ ] Lint 通过或差异已接受。
- [ ] Code Splitting / Lazy Loading 没有明显退化。
- [ ] Bundle 变化已检查（高风险时）。
- [ ] 关键页面性能没有不可接受退化。
- [ ] 没有明显重复请求或无限 Effect / Render。
- [ ] 没有内存泄漏、未清理 listener / timer 等明显问题。

## 十三、多 Agent 集成

- [ ] Workstream 所有权没有冲突。
- [ ] Shared Route / Store / Theme / Token 由明确所有者维护。
- [ ] Worker 的全局变更提案已处理。
- [ ] 各页面实现没有形成互相不一致的局部架构。
- [ ] 已执行跨 Workstream E2E / Visual / Integration 验证。

## 十四、发布与清理

- [ ] 发布策略明确。
- [ ] Feature Flag / 灰度方案明确（如适用）。
- [ ] 回滚方式明确。
- [ ] 旧 Route 清理条件明确。
- [ ] 旧 Component / Store / CSS 清理条件明确。
- [ ] 旧 Asset / Icon / Font 清理条件明确。
- [ ] 临时兼容层有删除条件。
- [ ] `.migration/tests/` / `scripts/` 的长期去向明确。

## 十五、完成声明

只有阻断项目全部通过或由用户明确接受后，才允许声明前端迁移完成。

完成声明至少列出：

- 已迁移并验证的 Active / Conditional 功能；
- 明确不迁移的 Deprecated / Removed 功能；
- 页面和 Route 覆盖；
- 视觉 / 响应式验证结果；
- 交互和 UI 状态验证结果；
- 已批准视觉或产品差异；
- Accessibility 遗留项；
- 目标原生审查结果；
- 发布 / 回滚状态。
