## 任务拆分硬规则

禁止把以下内容直接作为任务目标：

```text
迁移 XxxService.java
迁移 XxxRepository.cs
把 old-module/utils 复制到新项目
将源类 A/B/C 改写成目标语言
```

任务目标必须表达目标项目要获得的能力、规则、契约或迁移基础设施，例如：

```text
实现“创建订单”用例
实现“取消订单”的状态与权限规则
接入订单持久化并保持事务语义
实现 OrderCreated 事件并验证幂等
```

源文件只允许出现在“来源证据”字段中。

## 任务开始前自检

- [ ] 任务名称不是源文件 / 类 / 函数名驱动。
- [ ] 已明确对应的能力和业务规则。
- [ ] 已有迁移语义规格，而不是直接把源实现作为任务说明。
- [ ] 已找到目标项目范例或明确说明为何没有可用范例。
- [ ] 目标文件与模块规划来自目标实现蓝图，而不是源目录树。
- [ ] 已确认目标项目有哪些能力可以直接复用。
- [ ] 验证方式在编码前已经定义。
