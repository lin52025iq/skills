# 功能生命周期清单

> 用于判断“仓库中存在的功能代码”当前是否仍属于需要迁移的产品能力。前端项目必须特别检查注释、路由、菜单、条件渲染、Feature Flag、权限和替代实现。

## 状态定义

- Active：现役，可正常触达。
- Conditional：条件现役，仅特定权限 / Flag / 租户 / 地区 / 数据状态 / viewport 可见。
- Hidden：UI 默认隐藏，但仍可能通过其他入口触达。
- Disabled：明确被配置或注册机制关闭，未来可能恢复。
- Deprecated：已有明确废弃或替代证据。
- Removed：产品能力已正式移除，仅剩残留代码或资源。
- Unknown：证据不足或冲突。
