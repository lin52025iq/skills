## 前端 Copy-Smell 清单

出现任一项都必须解释；阻断级未解释项不能通过。

- [ ] 是否把一个源 `.vue` / Angular Component 一对一翻成 `.tsx`？
- [ ] 是否把源页面组件树完整复制到目标页面？
- [ ] 是否把旧 Store module 原样搬成新 Store module？
- [ ] 是否批量复制 helper / mixin / base component？
- [ ] 是否复制旧 CSS / Less 架构而没有采用目标 Styling 惯例？
- [ ] 是否出现 Angular-shaped React / Vue-shaped React 等结构？
- [ ] 目标项目已有 Component / Hook / API Client / Layout 是否被重复实现？
- [ ] 是否因为换组件库导致视觉和交互静默漂移？
- [ ] 是否存在未经批准 redesign？
