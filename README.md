# 项目迁移 Skill

这是一个面向 AI 编程代理的系统迁移 Skill，用于将一个项目中的功能、模块或系统能力迁移到另一个项目中，并支持跨语言、跨框架、跨数据库、跨架构的迁移场景。

当前版本坚持以下原则：

- 不依赖预置分析脚本，由 AI 直接阅读代码、测试、配置、接口定义与数据约束来理解系统。
- 不把迁移等同于代码翻译，迁移目标是业务能力、行为、数据、接口与运行特性的可验证延续。
- 所有重要结论必须区分“证据、推断、未知”，禁止把推断伪装成事实。
- 在源系统未理解、迁移边界未确定、验收标准未建立之前，不允许进入大规模实现。
- 默认采用增量迁移，要求每个迁移单元可验证、可审查、可回滚。
- Skill 的工作语言始终为中文。
