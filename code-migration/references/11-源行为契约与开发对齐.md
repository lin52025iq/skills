# 11 源行为契约与开发对齐

## 目标

减少“文档理解正确，但开发过程中细节逐渐偏离 Source”的问题，同时明确 Discovery、Atomic Item、源行为、交互语义和页面结构之间的职责边界。

```text
Source Evidence
→ Discovery / Provenance
→ Source Behavior
→ Target Decision
→ Atomic Item
→ Implementation
→ Behavior / Interaction / Structure Validation
```

## 源行为之前先确认范围真实

中/高风险功能不要从粗粒度 Feature 直接进入 Source Behavior。先确认：

1. **Discovery**：入口、条件分支、权限、Flag、API 反向调用、自动行为、测试、异常恢复已达到“足够进入实施”；
2. **Provenance**：正式 Feature / Atomic Item 有源证据、用户明确新增、目标产品要求或 Target 强制约束。

`推断候选 / 未知` 不得静默升级成必需范围。

## 行为决策

```text
保持 / 目标修改 / 不迁移 / 未知
```

`保持` 保留可观察业务语义；`目标修改` 验证批准后的 Target Behavior；`不迁移` 记录依据；关键 `未知` 进入澄清或阻塞。

## 权威边界

```text
03 = Feature / optional Group / Atomic Item / 来源 / 实施事实
04 = 可选复杂业务语义，不维护进度
05 = Source Behavior / Target 业务语义 / 行为验证（WHAT）
06 = 页面结构 / 交互体验 / 响应式 / 用户新 UX（HOW / WHERE）
```

不要在 `05` 中复制 Atomic Item 实施状态，也不要用 `05` 代替复杂页面的 `06` 体验契约。

## 源行为覆盖 Gate

中/高风险功能实施前按风险确认：

- [ ] Discovery 足够进入实施；
- [ ] 正式 Atomic Item 有合法来源；
- [ ] 关键源行为已盘点且按需要有稳定 ID；
- [ ] 每条关键行为已有 `保持 / 目标修改 / 不迁移 / 未知` 决策；
- [ ] 所有关键“保持”行为至少映射一个范围内 Atomic Item；
- [ ] 所有“目标修改”有明确 Target Behavior；
- [ ] 权限、状态、错误、导航、数据契约、副作用等关键维度已覆盖；
- [ ] 不存在会改变当前实现方向的关键未知。

## Atomic Item 映射

```text
F-ORDER-I07
Atomic Item：返回订单列表后保留筛选上下文
来源：Source Evidence
处理方式：修改现有
关联 Source Behavior：SB-ORDER-014
```

规则：

- 关键“保持”行为没有 Atomic Item → 迁移遗漏；
- Atomic Item 没有 Source Behavior 且不是明确新增 → 检查来源依据；
- 一个 Source Behavior 可以映射多个紧密相关 Atomic Item；
- 一个 Atomic Item 也可以覆盖多个紧密相关行为，不强制一对一。

## WHAT 与 HOW / WHERE

`05` 记录业务上**必须发生什么**：

```text
409 后必须允许恢复操作
返回列表后必须保留用户上下文
```

`06` 记录用户**具体如何体验**：

```text
Drawer 是否关闭
输入如何保留
错误提示 / Focus 如何表现
filter / page / scroll 如何恢复
Desktop / Mobile 区域如何排列
```

不要在两个文档重复维护完整交互时序。

## 开发中对齐

```text
03：确认 Atomic Item 来源与实施
→ 处理要求满足
→ 05：验证 WHAT
→ 06：复杂前端验证 HOW / WHERE
→ 派生 Feature / Module 完成状态
```

不要等整个页面结束后才一次性回看 Source。

## 新发现能力

发现新能力时：记录候选 → 判断来源 → 判断范围 → 拆成合理 Atomic Item → 检查条件 / 权限 / 错误 / 副作用 → 更新 Discovery 和风险级别 → 必要时更新输入基线。

不能因为实现中“顺手想到更好体验”就直接新增产品能力。

## 验证负责人职责

至少确认：

- 无来源功能没有混入正式范围；
- 没有明显未检查的隐藏入口、条件能力或副作用；
- 保持行为真实存在于 Target；
- 目标修改符合批准后的 Target Behavior；
- 复杂交互和页面结构符合 `06`；
- 没有关键 Source Behavior 未覆盖。

## 运行时产物

```text
低风险：03 + 最小必要验证
中风险：03 + 关键 05；复杂前端按需 06
高风险：03 + 完整 05 + 复杂前端 06 + 独立验证
```
