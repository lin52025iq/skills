# 02 迁移约束与开发规则

> 这是迁移过程中由用户、目标项目或已确认迁移决策定义的长期执行规则。**长周期迁移中新对话必须在范围建模和开发前读取本文件。**

## 使用原则

1. 用户当前明确规则优先于 Agent 偏好；
2. 每条规则标明作用域、触发条件和强度；
3. `必须 / 禁止 / 必须询问` 属于强约束；
4. `建议` 允许有证据地偏离，但要记录原因；
5. 规则变化更新状态，不删除历史依据；
6. 不把一次性聊天偏好自动升级为长期规则；
7. 用户当前对话中的最新明确指令高于本文件旧规则。

## 规则强度与状态

```text
强度：必须 / 禁止 / 必须询问 / 建议
状态：生效中 / 已暂停 / 已失效
```

## 工具使用规则

当 `必须` 规则要求指定工具时，先确认工具存在、权限和环境支持。

如果不可用：

```text
相关原子功能项 / 工作流 = 已阻塞
```

并记录阻塞原因、解除条件、不可用工具和可选替代方案。**不得静默改用替代工具。**

## 新对话恢复

1. 读取 `00-迁移状态总览.md`；
2. 读取本文件所有 `生效中` 规则；
3. 与用户当前最新指令、已确认决策、Target 强制规则做冲突检查；
4. 根据当前模块 / 功能 / 原子功能项 / 工作流筛选有效规则；
5. 开发前确认没有违反强规则；
6. 不重复询问已有明确答案。
