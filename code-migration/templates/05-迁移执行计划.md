## 会话交接检查

以下任一情况发生时执行本 Gate：

- 当前 Slice 通过 Done Gate；
- 准备结束当前开发会话；
- 准备切换 Agent / 新对话；
- 当前 Slice 被 `MUST_ASK` 阻塞，需要等待用户；
- 发现 `.code-migration/` 与 Git/代码状态不一致。

### Session Handoff Gate

- [ ] 更新 NOW / READY / BLOCKED / DEFERRED / DONE
- [ ] 写清本轮最后完成的代码动作和验证结果
- [ ] 记录未完成但已经开始的工作，避免下一对话重复实现
- [ ] 将新发现的业务规则、目标架构约束或 Decision 写回对应文档
- [ ] 更新 `00-迁移状态总览.md` 的 Current Slice、最近完成、风险和 Recommended Next Action
- [ ] 更新状态总览中的 Branch / Last Related Commit / Working Tree / Last Updated At
- [ ] 如有未提交改动，明确文件范围、已完成部分、未验证部分和下一安全动作
- [ ] 如在等待用户回答，记录 Open Questions、已问内容和下一轮应继续问什么
- [ ] Files / Modules To Read First 已缩小到新对话真正需要的最小集合
- [ ] 若文档与代码状态无法确认一致，设置 `State Freshness = RECONCILE_REQUIRED`

## 恢复后的 Reconcile Gate

新对话发现 `RECONCILE_REQUIRED`、Working Tree 不明或文档与代码冲突时：

- [ ] 检查当前 Git 分支和工作区
- [ ] 检查最近相关提交
- [ ] 检查 Current Slice 相关文件
- [ ] 区分已完成、未验证、半完成和未开始
- [ ] 修正 NOW / DONE / BLOCKED
- [ ] 更新 `00-迁移状态总览.md`
- [ ] 只有状态重新一致后再继续写新代码
