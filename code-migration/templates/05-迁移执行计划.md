## 会话交接检查

结束当前开发会话、切换 Agent 或进入新对话前：

- [ ] 更新当前 Feature 的生命周期状态，不把半完成工作标为 `MIGRATED`
- [ ] 更新 NOW / READY / BLOCKED / DEFERRED / DONE
- [ ] 写清最后完成的代码动作和验证结果
- [ ] 记录未完成但已经开始的工作，避免下一对话重复实现
- [ ] 将新发现的业务规则、Target Behavior 或 Decision 写回对应文档
- [ ] 更新 `00-迁移状态总览.md` 的 Current Slice、状态、最近完成、风险和 Recommended Next Action
- [ ] 如有未提交改动，明确文件范围和当前状态
- [ ] 如文档与代码状态不能确认一致，标记 `RECONCILE_REQUIRED`
