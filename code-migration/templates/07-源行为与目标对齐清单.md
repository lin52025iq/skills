## 进入源行为契约前

中/高风险功能应先满足：

- [ ] 功能发现覆盖已达到当前证据下可接受水平；
- [ ] 正式功能 / 子项都有合法来源；
- [ ] 推断候选 / 未知没有静默进入必需范围。

如果仍存在大量未解释调用方、权限 / Flag / 状态分支、自动行为或测试隐含规则，先继续功能发现，不要急着宣布 Source Coverage 完整。

## 源行为当前状态

```text
未开始 / 待验证 / 验证中 / 验证失败
已完成 / 已阻塞 / 已延后 / 不适用
```

推导：

1. `阻塞状态=已阻塞` → `已阻塞`；
2. `目标决策=不迁移` → `不适用`；
3. 明确延后 → `已延后`；
4. `验证状态=失败` → `验证失败`；
5. 关联功能子项尚未满足处理要求 → `未开始`；
6. 关联功能子项已满足处理要求 + 未验证 → `待验证`；
7. `验证状态=验证中` → `验证中`；
8. `验证状态=通过/不适用` 且处理要求已满足 → `已完成`。
