## 源行为覆盖 Gate

按风险选择关键行为，不追求 ID 数量最大化。

- [ ] 关键业务行为已盘点；
- [ ] 关键行为有稳定 ID；
- [ ] 每条行为已决定 `保持 / 目标修改 / 不迁移 / 未知`；
- [ ] 每个“保持”行为映射至少一个范围内原子功能项；
- [ ] “目标修改”有明确目标期望行为；
- [ ] “不迁移”有依据；
- [ ] 关键权限、状态、错误、导航、数据契约、副作用已覆盖；
- [ ] 不存在会改变当前实现方向的关键未知。

### ID 密度原则

只为**值得独立迁移追踪**的行为建立 ID。普通静态字段、显而易见且低风险的同类细节可合并记录，不机械为每个小动作建立 SB。
