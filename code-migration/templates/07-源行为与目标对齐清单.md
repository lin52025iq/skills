## 源行为当前状态

每条源行为直接显示：

```text
未开始 / 待验证 / 验证中 / 验证失败
已完成 / 已阻塞 / 已延后 / 不适用
```

源行为当前状态主要由目标决策、关联功能子项和验证状态推导：

1. `阻塞状态=已阻塞` → `已阻塞`；
2. `目标决策=不迁移` → `不适用`；
3. 明确延后 → `已延后`；
4. `验证状态=失败` → `验证失败`；
5. 关联功能子项尚未满足实施要求 → `未开始`；
6. 关联功能子项已满足实施要求 + 未验证 → `待验证`；
7. `验证状态=验证中` → `验证中`；
8. `验证状态=通过/不适用` 且关联功能子项处理要求已满足 → `已完成`。

> 源行为不再单独维护“实施状态”，避免与 `02` 双写。

## 源行为覆盖检查门槛

中/高风险功能进入实施前确认：

- [ ] 关键源行为已盘点；
- [ ] 每条关键行为有稳定行为 ID；
- [ ] 每条行为已有 `保持 / 目标修改 / 不迁移 / 未知` 决策；
- [ ] 所有“保持”行为至少映射一个范围内功能子项；
- [ ] 所有“目标修改”都有明确目标期望行为；
- [ ] 所有“不迁移”都有依据；
- [ ] 权限 / 状态 / 错误 / 导航 / 数据契约等适用维度已覆盖；
- [ ] 不存在会改变实施方向的关键“未知”。

