# 03 迁移模块索引与进度

> 顶层模块导航与派生进度索引。**本文件不是详细 Feature / Atomic Item 状态权威源。** 对已经拆入 `modules/<module>/` 的模块，详细范围、原子功能项和实施状态以该模块的 `01-模块功能点.md` 为准；本文件只保存可快速恢复的派生摘要和相对链接。

## 核心原则

```text
顶层 03
= Module Index + Derived Progress

modules/<module>/01-模块功能点.md
= 该 Module 的 Feature / optional Group / Atomic Item 权威源
```

不得在两处完整复制同一模块的 Atomic Item 状态。

## 模块化触发条件

以下任一情况成立时，优先创建 `modules/<module>/`：

- 模块包含多个需要独立追踪的 Feature；
- Atomic Item 平铺在顶层会明显降低可读性；
- 模块需要跨会话持续推进；
- 模块有独立 Workstream / 并行边界；
- 模块需要自己的功能语义、源行为或页面结构/交互契约；
- 模块风险较高，需要独立验证或集成结论。

简单低风险模块可以直接保留在本文件，不为了形式创建模块目录。

## Checkbox 规则

Checkbox 只是 **完成投影（Completion Projection）**，不是状态输入。

```text
真实 Atomic Item 状态
→ 派生 Feature 生命周期
→ 派生 Module 状态
→ 同步 [ ] / [x]
```

- Module `[x]` ⇔ 模块派生状态=`已完成`；
- Feature `[x]` ⇔ Feature 生命周期=`已迁移 / 已清理`；
- Atomic Item `[x]` ⇔ Atomic Item 当前状态=`已完成`；
- 其他状态全部使用 `[ ]`，并在旁边显示真实状态。

**禁止仅通过手工把 `[ ]` 改成 `[x]` 来推进迁移状态。**

### Module 完成 Gate

Module 只有在以下条件同时满足时，Checkbox 才能变成 `[x]`：

- [ ] 所有范围内必需 Feature 达到目标生命周期；
- [ ] 不存在必需 Feature 未完成、验证失败或阻塞；
- [ ] 模块共享 Route / API / State / Permission / Layout / Style 的必要集成验证通过；
- [ ] 模块级用户目标与已确认新方案成立；
- [ ] 模块详细文档的真实状态与本索引摘要一致。

## 未拆目录的小模块

仅用于确实很小、没有独立维护价值的模块。达到模块化触发条件后，应把详细事实下沉到 `modules/<module>/`，本节改为链接摘要。

### M-SMALL 示例

- [ ] F-001 小功能 — `开发中`
  - [x] F-001-I01 已完成原子项
  - [ ] F-001-I02 待完成原子项 — `开发中`

## 模块目录标准

按复杂度自适应：

```text
modules/<module>/
├── 00-模块总览.md              # 模块入口，模块化时默认创建
├── 01-模块功能点.md            # 详细 Feature / Atomic Item 权威源
├── 02-功能语义.md              # 复杂业务语义按需
├── 03-源行为对齐.md            # 中/高风险按需
└── 04-页面结构与交互.md        # 复杂前端按需
```

### 文档权威关系

```text
00-模块总览
= 模块导航 + 派生摘要 + Feature Checklist

01-模块功能点
= Feature / Group / Atomic Item / 实施状态权威源

02-功能语义
= 模块私有业务语义，不维护进度

03-源行为对齐
= 模块私有 WHAT / 行为验证

04-页面结构与交互
= 模块私有 HOW / WHERE / 前端体验验证
```

顶层 `04 / 05 / 06` 只保存真正的全局或跨模块内容；模块私有事实优先放模块目录，避免双写。

## 导航要求

模块文档使用相对链接：

```text
顶层 03
→ modules/<module>/00-模块总览.md

模块 00
→ ../../00-迁移状态总览.md
→ ../../03-迁移模块索引与进度.md
→ 01-模块功能点.md
→ 可选 02/03/04
```

链接失效应视为迁移工作区一致性问题并修复。
