4. `02` 功能范围/来源/实施事实、`07` 源行为验证事实、`08` 页面结构/交互验证事实；
5. 执行计划；
6. 本状态总览。

## 新对话恢复步骤

1. 读取本文件，恢复总体风险、用户新方案和活跃工作流；
2. 读取用户规则；
3. 读取 `02`，恢复功能来源、范围、处理方式和实施状态；
4. 中/高风险时恢复功能发现覆盖与 `07` 源行为状态；
5. 复杂前端页面读取 `08`，恢复目标区域树、交互契约和验证差异；
6. 读取执行计划和输入基线；
7. 核对 Git、工作区、代码和测试；
8. 不一致时只对受影响范围重新校准。
