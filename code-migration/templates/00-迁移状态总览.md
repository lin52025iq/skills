## 新对话恢复步骤

新的 Agent / 新对话开始继续迁移时：

1. 先读取本文件，不要直接重新扫描所有源项目；
2. 读取 `01-迁移任务上下文.md`，确认总体目标、范围和目标架构没有变化；
3. 根据 `Current Module / Region` 读取对应 `modules/<module>/`；
4. 读取当前 Slice 相关的功能清单、执行计划和 Decision；
5. 检查目标仓库当前 Git 状态与最近相关提交，确认文档状态没有落后于代码；
6. 用一句话复述 Overall Goal、Current Slice、Done 条件、Blocked/Unknown 和下一步；
7. 只有发现文档与代码冲突、关键证据缺失或用户改变目标时，才重新扩大侦察范围。
