## 公共功能准入检查

- [ ] 至少被多个业务模块实际依赖，或明确作为跨模块业务能力；
- [ ] 具有独立业务或用户可观察语义；
- [ ] 可以独立实施和验证；
- [ ] 不是仅因为代码复用而产生的组件、工具函数、Hook 或样式；
- [ ] 业务模块没有复制本文件中的详细状态。

## 完成规则

公共功能是否完成只由本文件中的真实原子功能项、验证和必要集成结果派生。业务模块可以记录“公共依赖是否满足”，但不得反向修改公共功能状态。
