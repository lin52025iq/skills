## 原子性检查

- [ ] 每个 Atomic Item 只有一个主要产品 / 工程语义；
- [ ] 有可观察或可证明的结果；
- [ ] 可独立判断实施与验证；
- [ ] 没有复合多个可独立失败点；
- [ ] 没有拆到 DOM / 函数 / 变量等实现细节；
- [ ] Group 只在确实提高可读性时使用。

## 来源真实性检查

- [ ] 每个正式 Atomic Item 都有合法来源；
- [ ] `源系统证据` 可以指向证据；
- [ ] `新增` 有用户 / 产品 / 强制约束 / Decision 依据；
- [ ] `推断候选 / 未知` 未静默进入必需范围；
- [ ] 没有因为 Target 存在组件就自动新增产品能力。
