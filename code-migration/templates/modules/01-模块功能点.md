## 中文状态规范

### 原子功能项当前状态

```text
未开始 / 开发中 / 待验证 / 验证中 / 验证失败
已完成 / 已阻塞 / 已延后 / 不适用
```

### 功能生命周期

```text
已发现 → 已设计 → 实施中 → 验证中 → 已迁移 → 已清理
```

### 状态收敛

原子功能项详细字段优先于 `当前状态`，并按以下优先级收敛：

```text
范围外                         → 不适用
已明确延后                     → 已延后
已阻塞                         → 已阻塞
验证失败                       → 验证失败
验证中                         → 验证中
验证通过                       → 已完成
已实施/无需实施 + 验证不要求   → 已完成
已实施/无需实施 + 未验证       → 待验证
实施中                         → 开发中
未实施                         → 未开始
```

功能只有在全部范围内必需原子功能项完成，并且要求的发现、行为、交互、公共依赖和集成验证全部满足后，才能收敛为 `已迁移`；完成遗留清理后才能进入 `已清理`。

如果详细字段、生命周期、摘要或 Checkbox 冲突，始终从详细权威事实向上重新派生，禁止为匹配摘要而修改真实失败状态。

### Checkbox 完成投影

```text
原子功能项当前状态 = 已完成       → [x]
功能生命周期 = 已迁移 / 已清理     → [x]
其他                               → [ ]
```

Checkbox 不是状态输入；禁止仅勾选 Checkbox 推进状态。
