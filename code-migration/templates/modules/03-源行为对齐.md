## Source Behavior Gate

- [ ] 关键行为有稳定 ID；
- [ ] 每条行为已有目标决策；
- [ ] “保持”行为映射至少一个范围内 Atomic Item；
- [ ] “目标修改”有明确 Target Behavior；
- [ ] 关键权限、状态、错误、导航、数据契约、副作用已覆盖；
- [ ] 不存在会改变实现方向的关键未知。
