## 适用边界

应放入公共模块：

- 跨多个业务模块复用；
- 有独立业务或用户可观察语义；
- 可独立判断实施和验证。

不应放入公共模块：

- 普通按钮、弹窗等 UI 组件；
- 工具函数、Hook、样式；
- 仅因为代码共享而产生的纯工程基础设施。
