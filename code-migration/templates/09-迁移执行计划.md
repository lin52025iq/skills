# 09 迁移执行计划

> 本文件只负责**工作流、临时执行批次和 Gate**。完整范围、原子功能项及其真实状态以 `03-迁移模块功能点清单.md` 为准。

## 执行模型

```text
Workstream = 负责人 + 修改边界 + 并行/隔离边界
Batch = 当前为了效率一起开发或一起验证的一组原子功能项
Atomic Item = 唯一长期细粒度完成事实源
```

不维护独立 Slice 状态实体。Batch 是临时执行视图，不建立长期生命周期。

## 治理预算

- **低风险**：Feature + Atomic Item + 来源真实性 + 最小验证；不强制 Group、`05`、`06`、输入基线或 Batch。
- **中风险**：按需增加功能项组、关键 Discovery / SB / INT / REG、长任务输入基线。
- **高风险**：按需启用完整 `05 / 06`、Discovery、输入基线、独立验证、并行安全、集成验证、回滚 / 清理。

风险级别同时控制文档数量、ID 密度、Gate 数量和验证粒度。

## Ready Gate

开始 Workstream / Batch 前按风险确认：

- [ ] 功能与原子功能项拆分合理；
- [ ] 原子项具有可观察或可证明的完成结果；
- [ ] 正式原子项都有合法来源；
- [ ] 要求的 Discovery 足够进入实施；
- [ ] 要求的 `05` 源行为覆盖已完成；
- [ ] 复杂前端要求的 `06` 交互 / 页面结构目标已明确；
- [ ] 用户新方案已进入 Target；
- [ ] 验证方式、用户规则、依赖、目标落点满足；
- [ ] 并行时负责人和工作区边界明确。

### Discovery 足够进入实施

主要入口、关键 API/State/Event 反向调用、关键权限/Flag/状态分支、相关测试和来源分类已覆盖，且不存在会改变当前实现方向的关键未知即可；不要求证明绝对无遗漏。

|---|---|---|---|---|---|---|---|---|

同一原子功能项同时只能有一个生产代码负责人。

## 当前开发 Batch

仅在一次需要一起开发多个强关联原子项时记录：

| Batch | Workstream | 原子功能项 | 共享实现上下文 | 状态 |
|---|---|---|---|---|
| DEV-001 | WS-001 |  |  | `待执行 / 开发中 / 已完成 / 已阻塞` |

开发结束后逐原子项更新实施状态。Batch 完成不改变功能生命周期。

## 当前验证 Batch

仅在多个原子项适合在同一真实用户场景下一起验证时记录：

| Batch | Workstream | 原子功能项 | 验证场景 | 结果 |
|---|---|---|---|---|
| VER-001 | WS-001 |  |  | `未验证 / 验证中 / 通过 / 失败` |

每个原子项仍有独立验证结果和证据；单项失败不能被 Batch 通过覆盖，Batch 失败也不要求把其他已通过项改成失败。

## Workstream 完成条件

- [ ] 覆盖原子项状态与真实代码一致；
- [ ] 临时 Batch 结果已经逐项回写；
- [ ] 要求的 `05 / 06` 验证结果已同步；
- [ ] 输入基线无未处理漂移；
- [ ] Group / Feature / Module 状态已重新派生；
- [ ] 必要集成验证已更新。

## 功能完成 Gate

功能进入 `已迁移` 必须：全部范围内必需原子项完成、无必需项验证失败/阻塞、要求的 Discovery / `05 / 06` 验证通过、必要集成验证通过。

## 模块完成 Gate

模块只有在全部范围内必需功能达到目标生命周期、无未完成/失败/阻塞功能、模块共享边界必要集成验证通过且模块用户目标/新方案成立后才可 `已完成`。

```text
Batch 已完成 ≠ Workstream 已完成 ≠ Feature 已迁移 ≠ Module 已完成
```

## 并行与集成

Workstream 才是并行边界。并行前检查共享文件、Route/Layout/State/Query、API/契约、权限/状态机、公共基础、lockfile、registry/generated、全局样式和发布依赖。

环境不支持子 Agent / worktree / 安全隔离时，不伪造并行，保留 Workstream 模型并串行执行。

共享 Route/Layout、API/Query/State、权限、依赖/lockfile、Design System/全局样式、registry/generated 或同一发布批次时执行必要集成验证。

## 交接

暂停或切换 Agent 前记录 Workstream、当前功能/原子项、真实实施/验证状态、未完成和阻塞、输入基线（如要求）、尚未结束的临时 Batch 和下一安全动作。
